# Detection accuracy on MVTec AD's official test split

Generated by `training/report.py` from the MLflow runs. Do not edit by hand.

- **Image AUROC**: how well the score separates good parts from defective ones (1.0 is perfect, 0.5 is a coin toss). It does not depend on a threshold.
- **F1 held out**: the threshold is tuned on half of the test images and scored on the other half, averaged over 10 random halves. This is the honest figure.
- **F1 optimistic**: the threshold is tuned on the same images it is scored on. Shown because papers usually report it this way.
- **Pixel AUROC**: how well the heatmap matches the hand-drawn defect masks.

MVTec has no separate labelled set to tune a threshold on, which is why both F1 figures are shown.

Fit times are rough: they include reading the images from disk, and some runs shared the laptop with other programs.
